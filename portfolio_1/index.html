귀사는 대용량 콘텐츠 생태계를 리드하며 혁신적인 미디어 서비스를 선보이고 있습니다. 저는 FastAPI 비동기 프레임워크 기반의 AI 모델 서빙 파이프라인과 피그마(Figma) 기반의 정교한 프론트엔드 컴포넌트 라이브러리를 융합하여 귀사의 콘텐츠 플랫폼 생성 비용을 대폭 절감하고, 사용자에게 몰입감 있는 생성형 미디어 경험을 선사하기 위해 지원했습니다.

입사 후 1년 이내에 **FastAPI 기반 AI 영상 생성 비동기 큐**를 고도화하여 렌더링 처리 속도를 40% 이상 개선하고, 3년 이내에는 피그마 연동 디자인 시스템과 프론트엔드 타임라인 UI를 결합한 차세대 'AI 숏폼 자동 제작 플랫폼' 개발의 핵심 엔지니어로 성장하겠습니다.

[미디어 프론티어] 마스터 클래스 캡스톤 프로젝트로 '실시간 AI 숏폼 영상 제작 웹'을 구축할 당시, 멀티모달 AI 모델 동시 호출 시 동기식 처리로 인해 서버 타임아웃과 15초 이상의 대기 지연이 발생하는 심각한 병목 현상을 맞닥뜨렸습니다.

S (Situation): 대용량 AI 영상제작 요청 시 기존 백엔드 블로킹 문제로 15초 이상 서버 지연 및 동시 요청 다운 현상 발생.
T (Task): FastAPI 및 비동기 파이프라인 도입으로 영상 생성 처리 대기 시간을 5초 이내로 단축 및 서버 안정성 확보.
A (Action): Python FastAPI의 `asyncio` 및 Celery + Redis 비동기 태스크 큐 구조 구축, AI 워크플로우 이벤트 렌더링 분산 처리.
R (Result): AI 영상제작 응답 속도 70% 단축, 대용량 비동기 태스크 동시 100건 처리 성공, 우수 프로젝트 수상.

문제 해결을 위해 기존 동기식 구조를 파기하고 FastAPI의 비동기 이벤트를 적극 활용했습니다. AI 영상 생성 작업을 백그라운드 워커(Celery/Redis)로 이관하고, 클라이언트 프론트엔드에는 Server-Sent Events(SSE) 방식을 도입하여 실시간 생성 진행률(0~100%)을 즉각 시각화했습니다. 그 결과, 사용자 체감 대기 시간을 70% 줄이고 안정적인 서비스 운영을 달성할 수 있었습니다.

저는 이를 극복하고자 피그마(Figma) 디자인 변수(Variables)를 프론트엔드(React/Tailwind) 코드와 직접 동기화하는 자동화 빌드 스크립트를 구축했습니다. 피그마에서 업데이트된 레이아웃 및 디자인 토큰이 Git CI/CD를 통해 프론트엔드 코드 베이스로 즉시 반영되도록 유도했습니다.
